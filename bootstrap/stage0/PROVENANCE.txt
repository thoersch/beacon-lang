Beacon Stage-0 bootstrap seed
=============================

Purpose: frozen CLR bootstrap/runtime boundary for the self-hosted Beacon compiler.
Seed refresh: introduces one reusable, versioned hostNative(module, request) extension ABI for trusted local .NET assemblies and exposes the native handle of a Beacon window to standard-library code. No OpenGL, WGL, Silk.NET, OpenTK, or other graphics binding is included in Stage-0. All prior inspection, native UI, and typed List behaviors are preserved.
Historical implementation language: C#
Source branch: feature/graphics-opengl-native-extension
.NET SDK: 10.0.403

Temporary reconstruction sources are removed after verification. The independent native/opengl/ assembly contains WGL/OpenGL bindings and can evolve separately from the bootstrap.
Beacon's canonical compiler remains in compiler/.
