Beacon Stage-0 bootstrap seed
=============================

Purpose: immutable CLR bootstrap/runtime boundary for the self-hosted Beacon compiler.
Seed refresh: refines the existing hostWindow(action, payload) Windows backend with dark window chrome, modern typography, themed edit controls, owner-drawn buttons and panels, and consistent native colors. UI structure, layout, semantic visual roles, and callback routing remain Beacon code under std/ui.beacon. Native visual resources are initialized only after entering the Windows-only boundary, preserving portable Stage-0 startup. hostCharacter(Number), flattened else-if support, and the reduced filesystem/path boundary are preserved.
Historical implementation language: C#
Source branch: refine/polished-native-ui
.NET SDK: 10.0.403

The one-time C# refresh source was reconstructed from the verified historical migration lineage and removed after this seed was built and fixed-point verified.
The canonical compiler implementation remains Beacon source under compiler/.
