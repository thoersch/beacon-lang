Beacon Stage-0 bootstrap seed
=============================

Purpose: immutable CLR bootstrap/runtime boundary for the self-hosted Beacon compiler.
Seed refresh: preserves hostCharacter(Number) and adds hostWindow(action, payload), the irreducible native desktop boundary used by std.window and std.ui. Beacon owns the UI tree, layout, callback routing, and event loop. The initial native backend is Win32; the seed remains portable and reports window availability explicitly on unsupported platforms. Flattened else-if parser support and the reduced filesystem/path host boundary are preserved.
Historical implementation language: C#
Source branch: feature/window-ui
.NET SDK: 10.0.403

The one-time C# refresh source was reconstructed from the verified historical migration lineage and removed after this seed was built and fixed-point verified.
The canonical compiler implementation remains Beacon source under compiler/.
