Beacon combines explicitly typed declarations, functions, Lists, Records, and native CLR execution with an unusually small compiler foundation: **Atom**, **List**, and **Record**.

## A language you can read

```beacon title="hello.beacon"
person: type = {
    name: string

    greet: fn() = "Hello, {.name}!"
}

ada: person = { name: "Ada" }
print(ada.greet())
```

```text
Hello, Ada!
```

## Three structural forms, one compiler model

Beacon reduces ordinary language constructs to Atoms, Lists, and Records. The self-hosted compiler is split into understandable Beacon modules, produces a symbolic CLR plan, and verifies a fixed point against the frozen Stage-0 bootstrap.

The goal is a useful language and toolchain whose essential behavior remains expressible in Beacon.

## Current scope

Beacon runs programs on the CLR, includes core standard libraries, and has an initial native Windows desktop UI. Live inspection is opt-in and read-only. The language is experimental; packaging, debugging features, and additional platform UI backends are still developing.
